# Audit — what this repository actually did (2026-09-05)

Run in response to a reviewer's comparison with two supervised detectors (AVoiD-DF,
AuViRe) that share a seed-42, 1,000-video, 600/200/200 protocol. Every statement below
was checked against the code and the shipped files, not against the docs.

## Protocol, as implemented (`_inner.py: stage_metadata`)
- Labels: a LAV-DF clip is **fake (1)** if `modify_video` or `modify_audio` is set or it
  has any `fake_periods`; otherwise **real (0)**. Clips under 31 frames are dropped.
- Training pool = real clips from LAV-DF's own `train` split; validation pool = real
  clips from `dev`; test pool = LAV-DF's own `test` split (both classes).
- `test_balanced=True`: 500 real + 500 fake sampled from the test pool. `seed=42`.
- Assertion in code: train and val contain no fakes (AVH-Align's objective is
  real-only by design).

## What the reviewer got right and what does not follow
Right: the run trains on 3,000 real clips, validates on 300 real, tests on 1,000
(500/500), up to 40 epochs with early stopping (best epoch 27, stopped after 37), batch
1024, Adam 1e-5, with AVH-Align's alignment objective. All of that is in the code and
the notebook CFG (`max_train=3000, max_val=300, max_test=1000, test_balanced=True, seed=42`).

Does not follow: "change AVH-Align to the 600/200/200 supervised protocol". AVH-Align is
a self-supervised, real-only method; it has no classification loss to swap in and its
head outputs an alignment score. Optimiser, batch and epoch count are method-specific.

What a fair comparison needs instead:
1. **Same test clips.** Score this repository's trained checkpoint on the reviewers'
   exact seed-42 200-clip test set (the scorer accepts any clip list), and report
   AP/AUC on those 200 next to the other two methods.
2. **Overlap check.** Assert none of the 3,300 train/val clips here appears in that
   200-clip test set. Note the two protocols sample differently: this repository draws
   test clips from LAV-DF's official `test` split, whereas a seed-42 draw of 1,000
   videos from all 136,304 spans train/dev/test — so overlap is possible and must be
   measured, not assumed.
3. Optional same-budget row: retrain the head on only the real clips inside the shared
   600-clip training split, labelled as under-trained relative to the paper's 45k.
